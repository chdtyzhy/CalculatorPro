隐私政策

CalculatorPro
本应用不收集任何用户数据

本隐私政策说明 CalculatorPro（以下简称"本应用"）如何处理您的信息。我们高度重视您的隐私，并致力于保持完全透明。

1. 我们不收集的数据

本应用是一个离线计算器工具，不会收集、存储或传输任何个人数据。具体而言：

• 不收集姓名、邮箱、电话等个人身份信息

• 不收集设备标识符、位置信息或 IP 地址

• 不访问相机、麦克风、通讯录或相册

• 不使用 Cookie 或类似跟踪技术

• 不与任何第三方共享或出售任何数据

• 不包含任何第三方分析或广告 SDK

2. 本地存储的数据

您在使用本应用时产生的计算记录、设置偏好等数据仅保存在您的设备本地。这些数据：

  • 不会上传到任何服务器
  • 不会离开您的设备
  • 在您卸载本应用时将被一并删除

3. 儿童隐私

本应用适合所有年龄段用户使用，包括儿童。由于本应用不收集任何个人数据，因此不会对儿童隐私造成任何风险。

4. 第三方服务

本应用完全离线运行，不连接任何第三方服务或服务器，因此不涉及任何第三方数据处理。

5. 隐私政策的变更

如果未来本隐私政策发生任何变更，我们将在此页面更新政策内容并修改下方"最后更新"日期。我们建议您定期查阅本页面以了解最新信息。
